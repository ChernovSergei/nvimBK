# WordVim 6.79 — Title при повторном открытии

Pandoc переносил абзац Title в метаданные и исключал его из основного текста.
Теперь во временной копии входного DOCX стили Title/Subtitle получают временные
имена; после преобразования восстанавливаются исходные имена стилей. Положение
абзаца в документе сохраняется. Пользовательский файл при чтении не меняется.

Проверка на копии пользовательского Document.docx: текст Global ShortCuts,
стиль Title и следующий заголовок PowerShell, два цикла сохранения/открытия.

После установки перезапустите Neovim и откройте исходный DOCX заново.
