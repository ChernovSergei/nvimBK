# WordVim 6.80 — стабильная ширина панелей

Для левой и правой панелей стилей включён winfixwidth. Neovim больше не
расширяет левую панель при переводе фокуса и не делит экран пополам при
закрытии левой панели на входе в редактор таблицы.

Проверены повторные переходы между тремя окнами, вход и отмена редактора
таблицы с восстановлением левой панели. Настройки ширины панелей сохранены.
После установки перезапустите Neovim.
