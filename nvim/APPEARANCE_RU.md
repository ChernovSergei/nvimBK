# Цвет и шрифт — v6.65

Цвета редактора приближены к присланному скриншоту IntelliJ: тёмно-серый фон,
оранжевые ключевые слова, голубые методы, фиолетовые поля и жёлтые аннотации.
Настройка применяется ко всему редактору; для Java добавлены отдельные группы
Tree-sitter и JDTLS. Полная семантическая окраска требует работающего JDTLS.
Форматирование исходного кода не изменено.

Шрифт на скриншоте нельзя определить точно. Для близкого вида выбран JetBrains Mono,
Regular, размер 14 как начальная настройка. Размер можно подстроить под масштаб экрана.

Windows Terminal:
1. Скачайте JetBrains Mono с https://www.jetbrains.com/lp/mono/ и установите TTF.
2. Откройте настройки Windows Terminal → нужный профиль PowerShell → Внешний вид.
3. Выберите JetBrains Mono, размер 14, обычное начертание и сохраните.
   Чтобы применить ко всем профилям, измените Профили → По умолчанию → Внешний вид.
   Пример объекта для существующего профиля: tools/windows-terminal-font.json.
   Это фрагмент, не замена всего settings.json.

Linux: установите шрифт и выберите JetBrains Mono в настройках терминала.
Android proot: шрифт выбирается в приложении терминала на Android, не внутри proot.
Для GUI Neovim задан guifont=JetBrains Mono:h14; шрифт должен быть установлен.
Архив не устанавливает шрифты в ОС и не меняет настройки открытого терминала.

Установка конфигурации: закройте Neovim и замените файлы в %LOCALAPPDATA%/nvim
(Windows) или ~/.config/nvim (Linux/proot) файлами архива. Затем откройте Neovim.
