# WordVim 6.78 — абзацы и таблицы при вставке

- Убраны разделительные пустые строки Markdown между импортируемыми абзацами.
- Списки импортируются компактно, без сброса номера на каждом пункте.
- Ячейки хранят текст без видимых Markdown-звёздочек; жирное оформление переносится на уровень стиля ячейки.
- Неразрывный пробел в ячейке нормализуется до обычного пробела до удаления хвостовых пробелов.
- Windows HTML-фрагмент получает явное объявление UTF-8 после извлечения из буфера.

Проверены: явный пустой абзац, заголовки, список 1–3, кириллица, кавычки,
таблица с NBSP, объединённые ячейки, ссылки, импорт DOCX/изображения,
сохранение и повторное открытие DOCX.

Установите обновление, перезапустите Neovim и повторите вставку через Space w p.
Исходный пользовательский DOCX не изменён. Ранее повреждённые символы (например,
Â уже в исходнике) не исправляются автоматически. HTML без семантического
заголовка таблицы не позволяет надёжно восстановить этот признак; используйте
импорт исходного DOCX для более точного переноса. Смешанное оформление внутри
одной ячейки упрощается до стиля ячейки. Живая вставка из OnlyOffice не проверена.
