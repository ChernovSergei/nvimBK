# WordVim 6.77 — вставка из Office

Исправлен импорт HTML через Space w p / :WordPaste и :WordInsertFile:
- Служебные CSS-атрибуты Span/Div и заголовков удаляются до преобразования таблиц.
- Жирный текст, ссылки, заголовки и объединения ячеек сохраняются.
- Windows HTML clipboard читается напрямую как UTF-8, без ANSI-декодирования Windows Forms.
- Кавычки и тире не преобразуются Markdown writer в ASCII-замены.

После установки перезапустите Neovim. Отмените прежнюю неудачную вставку,
если она была последним действием (u), затем заново скопируйте фрагмент в
OnlyOffice и вставьте через Space w p. Исправление не очищает ранее сохранённый
текст с CSS автоматически. Полное воспроизведение исходного оформления Office
не поддерживается.

Проверки: HTML с CSS, кириллицей, кавычками, ссылкой, жирным текстом и colspan;
DOCX save/reopen с импортом текста, таблицы и картинки; компиляция Windows
clipboard reader. Живой буфер обмена OnlyOffice не проверялся.
