# WordVim Neovim Integrated v6_59

## Общая справка

F1 открывает и закрывает полноэкранную справку для Java, Node.js, DOCX,
редактора таблиц, боковых панелей и встроенного терминала. Работает также
во время ввода в ячейку: набранный текст возвращается в исходный запрос.
Space w h в Normal mode и :WordHelp остаются дополнительными способами вызова.

Справка содержит четыре раздела:
1. Команды текущего проекта: Java, Node.js, DOCX или таблица DOCX.
2. Neovim и плагины, настроенные в этой конфигурации.
3. Команды Linux shell.
4. Команды PowerShell.

Клавиши 1–4 переходят к разделам; j/k и Ctrl+d/Ctrl+u прокручивают;
q, Esc или F1 закрывают справку. В обычном окне справки / ищет текст.
При открытии поверх командной строки используется прокрутка и переход 1–4.
Размер справки следует за размером окна Neovim. Она занимает рабочую область
Neovim, не переключая само приложение в системный полноэкранный режим.

Первый раздел определяется по текущему файлу и ближайшему package.json,
pom.xml или Gradle/Maven wrapper; панели инструментов используют последний
редактируемый файл. Буферные сочетания с описаниями добавляются автоматически.
Команды сборки и запуска выполняются пользователем; справка их не запускает.
Java LSP, тесты и отладка требуют настроенных серверов/адаптеров исходного проекта.

## Shift+Enter — тест №6

Вставка разрыва строки теперь выполняется напрямую, сохраняя два завершающих
пробела Markdown и общий стиль абзаца. Обработчики обычного Enter и автопереноса
не участвуют. Запасное сочетание в Insert mode: Ctrl+g, затем Enter.
Если терминал передаёт Shift+Enter как обычный Enter, используйте запасное
сочетание: Neovim не может различить две клавиши с одинаковым входным кодом.

## Цвет боковых колонок

В редакторе стиля добавлено поле Panel color HEX. Enter на этом поле открывает
палитру; Custom HEX позволяет задать свой цвет. Поле также можно редактировать
вручную. Ctrl+s применяет цвет к левой и правой колонкам; пустое значение или
Automatic возвращает автоматический цвет. Color HEX по-прежнему задаёт цвет
текста в DOCX. Редактор доступен и через :WordStyleEdit.

Цвета панелей сохраняются локально в stdpath('state')/wordvim/panel-colors,
отдельно для полного пути документа и имени стиля. Они сохраняются между
запусками Neovim, но не переносятся внутри DOCX на другой компьютер или путь.
Цвет текста и остальные свойства документа сохраняются в DOCX командой :w.

## Масштаб изображения — тест №15

Исправлена интерпретация знака % как управляющего символа Lua gsub при замене
ширины изображения и восстановлении её из DOCX. :WordImageScale 50 задаёт
width=50%, а :WordImageResize 50 уменьшает текущую ширину вдвое.
Числовое представление Markdown в редакторе сохраняется; это не просмотр
изображения как в Word. Уже повреждённый текст старого документа автоматически
не восстанавливается: для него потребуется вернуть изображение из исходника.

## Установка

Закройте Neovim и сохраните резервную копию текущей конфигурации. Распакуйте
содержимое архива в папку конфигурации, где находится используемый init.lua,
с заменой файлов этой версии. Windows: обычно %LOCALAPPDATA%/nvim;
Linux: обычно ~/.config/nvim. Перезапустите Neovim. Системная конфигурация
и исходный пользовательский WordVim_Test.docx при подготовке архива не менялись.

## Проверки

Из корня распакованного проекта:

    nvim --headless -u NONE -i NONE -l tests_global_help.lua
    nvim --headless -u NONE -i NONE -l tests_help_modes.lua
    nvim --headless -u NONE -i NONE -l tests_image_percent.lua

Первые проверки используют реальный Neovim без загрузки внешних плагинов.
Проверка режимов запускает дочерний Neovim по RPC, включая таблицу и PowerShell.
Проверка метаданных DOCX требует Windows PowerShell и использует копию тестового
файла. Локальные тестовые настройки цветов записываются в work/test-state.

Проверено: контексты help, четыре раздела, изменение размеров, возврат без
потери текста, режим Insert и позиция курсора, терминал, ввод ячейки, таблица,
Shift+Enter и запасное сочетание, цвет колонок и его сохранение, ширина 50%,
повторное изменение ширины и сохранение/восстановление метаданных в DOCX ZIP.
Синтаксис всех Lua-файлов проверен.

Полный DOCX round-trip через Pandoc, визуальная проверка в Word/OnlyOffice,
физическая клавиша Shift+Enter в вашем терминале и реальные Java/Node.js
серверы не проверены в этой среде. Pandoc здесь отсутствует.
